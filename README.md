# GitHub Cards for AlonaBot

[中文文档、命令与 Webhook 配置](README.zh-CN.md)

Paste a GitHub repository, issue, or pull request link to get its original GitHub OpenGraph card. Look up details with `/ghissue`, `/ghpr` and `/ghreadme`, or use `/ghsub` to get updates in the current chat through polling or signed webhooks.

Install on AlonaBot 0.3.3:

```sh
alonabot install --source FlanChanXwO/alonabot-plugin-github-cards
```
